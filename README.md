## 👋 About me

I'm a **DevOps Engineer** based in São Paulo, Brazil, building and running cloud platforms on **AWS**.
My day-to-day is turning infrastructure into code and making delivery boring (in the good way):

- 🏗️ **Multi-account AWS** with SSO, provisioned end to end with **Terraform** and **Terraform Cloud**
- 🚀 **CI/CD pipelines** with **GitHub Actions** shipping containers to **ECS**, **EKS** and serverless (Lambda, EventBridge)
- 📈 **Observability** stacks with **Prometheus, Grafana, Loki and OpenTelemetry**
- 🔐 **Quality and access**: SonarQube, Keycloak, API gateways
- ☸️ Going deeper into **Kubernetes** and **GitOps** with **Argo CD** and **Helm**
